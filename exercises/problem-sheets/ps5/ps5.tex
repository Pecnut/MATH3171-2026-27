    % Q1
    \question{}{
        % Question
        \textbf{Allee population dynamics with spatial variations}

        \begin{enumerate}[label=(\alph*)]
            % (a)
            \item Consider a population $u(t)$ evolving according to
            \begin{equation}\label{Allee_ODE}
                \fd{u}{t} = ru\left(\frac{u}{A}-1\right)
                \left(1-\frac{u}{K}\right),
            \end{equation}
            with the parameters $r>0$, $K>0$ and $0 < A < K$.
            Explain the biological interpretation of the three parameters.

            % (b)
            \item Using linear stability analysis and/or a graphical
            representation of the phase space, explain the behaviour
            of the population $u$ satisfying \cref{Allee_ODE} for
            different initial conditions.

            % (c)
            \item Consider the spatial model for $u(x,t)$,
            \begin{equation}\label{Allee_PDE}
                \pd{u}{t} = D\nabla^2 u
                + ru\left(\frac{u}{A}-1\right)
                \left(1-\frac{u}{K}\right),
                \quad x \in \Omega = [0,L],
            \end{equation}
            where $u$ satisfies Dirichlet conditions on its boundaries
            of the form $u = u_B$ for $x = 0,L$, for some constant
            parameter value $u_B\geq0$. For what values of $u_B$ do
            spatially homogeneous equilibria exist? For all cases
            where they do exist, use a linear stability analysis to
            determine their stability as a function of the model
            parameters. For any of these cases where the spatial model
            can give a different stability prediction from the ODE,
            compute the critical domain length, $L_c$, where the
            stability of a spatially homogeneous equilibrium changes.

            % (d)
            \item Without redoing the linear stability analysis,
            explain what is different about the number and stability
            of equilibria of \cref{Allee_PDE} in the case of zero
            Neumann (no-flux) boundary conditions.
        \end{enumerate}
    }
    { % Solution
        \begin{enumerate}[label=(\alph*)]
            % (a)
            \item Interpretation of the three parameters:
            \begin{itemize}
                \item $r$ is the growth rate of the population,
                \item $K$ is the maximum carrying capacity,
                \item $A$ is the Allee parameter determining the
                threshold population.
            \end{itemize}

            \commentary{
                Broadly this part was fine, and credit was given
                generously. It is worth noting that $r$ is really a
                timescale of the whole process, both growth and death
                of the population, but for this course simpler
                descriptions are fine.
            }
            %
            % (b)
            \item This example is exactly done in the Michaelmas
            portion of the course. The three equilibria are
            $u_0=0, A, K$, which can be seen as the right-hand side
            is factored in terms of these three roots. Stability can
            be determined by signing $f'(u_0)$ in each case, where
            we compute:
            \begin{equation}
                f'(u_0) =
                r\left(\frac{u_0}{A}-1\right)
                \left(1-\frac{u_0}{K}\right)
                + \frac{ru_0}{A}\left(1-\frac{u_0}{K}\right)
                - \frac{ru_0}{K}
                \left(\frac{u_0}{A}-1\right).
            \end{equation}

            This is a nice form as for each of our equilibria above,
            two of the terms drop out in each case. So we have:
            \begin{itemize}
                \item $f'(0)<0$ so $u_0=0$ is stable,
                \item $f'(A)>0$ so $u_0=A$ is unstable,
                \item $f'(K)<0$ so $u_0=K$ is stable.
            \end{itemize}

            Another method is to compute this graphically by plotting
            $f'(u)$ against $u$:
            \begin{center}
                \includegraphics{allee-phase.pdf}
            \end{center}

            For the initial population $u(0)$,
            \begin{itemize}
                \item if $u(0)>A$ then $u \to K$ as $t \to \infty$,
                \item if $u(0)<A$ then $u \to 0$ as $t \to \infty$,
                so this models death of a sufficiently small
                population.
            \end{itemize}
            %
            % (c)
            \item Spatially homogeneous equilibria will exist only
            when $u_B=u_0$ for one of the three kinetic equilibria,
            \begin{equation*}
                u_B = 0, \quad u_B=A \quad\text{or}\quad u_B=K,
            \end{equation*}
            and in each case there will only be a single equilibrium.

            \paragraph{First consider $u_B=0$.}
            The only spatially homogeneous equilibrium in this case
            is $u_0=0$, as the other two would not satisfy the
            boundary conditions. Linearising about this equilibrium
            with $u=u_0+\varepsilon u_1$, we find:
            \[
                \pd{u_1}{t}
                = D\pdd{u_1}{x} - ru_1,
                \quad u_1(0,t)=u_1(L,t)=0,
            \]
            and hence perturbation growth rates (determined by
            $U = \exp(\lambda_k t)\sin(k\pi x/L)$) are:
            \[
                \lambda_k =
                -D\left(\frac{k\pi}{L}\right)^2-r,
                \quad k=1,2,3,\dots
            \]
            and hence $\lambda_k < 0$ so this equilibrium is always
            stable.

            \paragraph{Similarly we find for $u_B=A$:}
            \[
                \lambda_k =
                -D\left(\frac{k\pi}{L}\right)^2
                + r\left(1-\frac{A}{K}\right),
                \quad k=1,2,3,\dots
            \]
            which is more interesting.

            As $A<K$, we have that $1-A/K>0$ so that this
            equilibrium is unconditionally unstable in the ODE case.
            But here, as $k=1$ is the smallest spatial eigenvalue,
            we can have $\lambda_1$ with a negative sign for
            sufficiently small values of $L$, as in the
            `harsh environment' case seen in the lecture notes.
            We find a critical domain length:
            \[
                L_c = \pi\sqrt{\frac{DK}{r(K-A)}},
            \]
            such that $L>L_c$ makes $u_0=A$ unstable, but
            $L < L_c$ makes $u_0=A$ stable.

            \paragraph{For $u_B=K$:}
            we find exactly the same result as in $u_B=0$, with the
            equilibrium always being stable as long as it exists.
            The calculation is essentially identical in this case,
            except with $f'(K) = r(1-K/A)$, which is negative as
            $K>A$ so $K/A>1$.

            \commentary{
                A few issues/comments here:
                \begin{itemize}[topsep=1ex,itemsep=0pt]
                    \item It is worth really understanding why there
                    is only ever at most one equilibrium where
                    $u_B = 0, A,$ or $K$. Any solution $u(x,t)$,
                    which includes equilibrium solutions, \emph{must}
                    satisfy the boundary conditions.

                    \item You do not need to work out the separation
                    of variables solution every time, or even the
                    linearisation, unless you are asked to do this
                    precisely. As long as you know what the solution
                    ansatz is, or what the linear equation is, you
                    can just write it down.

                    \item It is important to understand why $k=1$
                    gives the largest growth rate here, and why this
                    can then impact stability.
                \end{itemize}
            }

            % (d)
            \item With zero Neumann conditions, we would allow any
            of the three homogeneous equilibria (as they all satisfy
            the boundary condition, since constants have zero
            derivative). The stability of the three equilibria would
            also not change from the ODE case, as
            $\lambda_0=f'(u_0)$, corresponding to $k=0$, is the
            largest growing mode, which is exactly what the ODE
            linear stability analysis gives as the growth rate.
        \end{enumerate}
    }

    % Q2
    \question{}{
        % Question
        \textbf{Spatial Lotka--Volterra}

        Consider the following spatial variant of the Lotka--Volterra
        system,
        \begin{align*}
            \pd{u}{t} &= \nabla^2 u + u - uv,\\
            \pd{v}{t} &= D\nabla^2 v - \gamma(v-uv),
        \end{align*}
        where $\gamma$ and $D$ are positive constants. The system is
        considered on a Cartesian domain
        $[0,L_1]\times[0,L_2]$ with a coordinate system
        $(x_1,x_2)$. Both $u$ and $v$ take on fixed values $u_0$
        and $v_0$ on the boundaries at all times.

        \begin{enumerate}[label=(\alph*)]
            % (a)
            \item Find the system's homogeneous equilibria.

            % (b)
            \item Determine any conditions on the domain lengths
            $L_1$ and $L_2$ for which the equilibria are
            asymptotically stable (if at all). In each case assume
            that the fixed boundary values correspond to the
            equilibrium under consideration.

            % (c)
            \item Consider small perturbations about the homogeneous
            equilibrium $(1,1)$. Find a condition on the domain
            lengths $L_1$ and $L_2$, and the parameters $D$ and
            $\gamma$, for which there exists at least one spatial
            mode which decays with oscillations in time.

            Is it possible for every spatial mode to exhibit
            oscillatory decay? Justify your answer.
        \end{enumerate}
    }
    { % Solution
        \begin{enumerate}[label=(\alph*)]
            % (a)
            \item The homogeneous equilibria satisfy
            \begin{equation*}
                u_0(1-v_0)=0,
                \qquad
                \gamma v_0(u_0-1)=0.
            \end{equation*}
            Hence the two homogeneous equilibria are $(0,0)$ and
            $(1,1)$.

            %
            % (b)
            \item Assuming solutions of the form
            \begin{equation*}
                u(x,t)=u_0+\epsilon u_1(x,t),
                \qquad
                v(x,t)=v_0+\epsilon v_1(x,t),
            \end{equation*}
            expanding to linear order gives
            \begin{align*}
                \pd{u_1}{t}
                &= \nabla^2 u_1+(1-v_0)u_1-u_0v_1,\\
                \pd{v_1}{t}
                &= D\nabla^2 v_1+\gamma v_0u_1
                +\gamma(u_0-1)v_1.
            \end{align*}

            The fixed boundary conditions imply $u_1=v_1=0$
            on the boundary of the domain. Hence we seek solutions
            of the form
            \begin{equation*}
                \mvec{u_1}{v_1}=
                \mvec{a}{b}\e^{\lambda t}
                \sin(k_1x_1)\sin(k_2x_2),
            \end{equation*}
            where
            \begin{equation*}
                k_1=\frac{n_1\pi}{L_1},
                \qquad
                k_2=\frac{n_2\pi}{L_2},
                \qquad
                n_1,n_2=1,2,\ldots.
            \end{equation*}

            Defining
            \begin{equation*}
                k_s=k_1^2+k_2^2=
                \pi^2\left(\frac{n_1^2}{L_1^2}
                +\frac{n_2^2}{L_2^2}\right),
            \end{equation*}
            we obtain the matrix eigenvalue equation
            \begin{equation*}
                \lambda\mvec{a}{b}=
                \mat{1-v_0-k_s}{-u_0}
                {\gamma v_0}{\gamma(u_0-1)-Dk_s}
                \mvec{a}{b}
                =A_1\mvec{a}{b}.
            \end{equation*}
            Non-trivial solutions require
            $\det(A_1-\lambda I)=0$.

            \paragraph{The equilibrium $(0,0)$}
            In this case the characteristic equation is
            \begin{equation*}
                (\lambda-(1-k_s))(\lambda+Dk_s+\gamma)=0.
            \end{equation*}
            Hence the eigenvalues are
            \begin{equation*}
                \lambda_1=1-k_s,
                \qquad
                \lambda_2=-Dk_s-\gamma.
            \end{equation*}

            The second eigenvalue is always negative, whilst the
            first is negative if $k_s>1$. For asymptotic stability
            this condition must be satisfied for every permissible
            spatial mode. Since $k_s$ takes its smallest value
            when $n_1=n_2=1$, the condition for asymptotic stability
            is
            \begin{equation*}
                \boxed{
                    \frac{1}{L_1^2}+\frac{1}{L_2^2}>
                    \frac{1}{\pi^2}.
                }
            \end{equation*}

            At equality the equilibrium is not asymptotically
            stable, since a small perturbation of $u$ proportional
            to the first spatial eigenfunction, with $v=0$, is
            itself a steady state.

            \paragraph{The equilibrium $(1,1)$}
            In this case the characteristic equation is
            \begin{align*}
                (\lambda+k_s)(\lambda+Dk_s)+\gamma &=0,\\
                \lambda^2+(D+1)k_s\lambda+Dk_s^2+\gamma &=0.
            \end{align*}

            The trace and determinant of $A_1$ are
            \begin{equation*}
                \tr(A_1)=-(D+1)k_s<0,
                \qquad
                \det(A_1)=Dk_s^2+\gamma>0.
            \end{equation*}
            These inequalities hold for every permissible spatial
            mode, since $k_s>0$. Hence $(1,1)$ is asymptotically
            stable for all finite positive domain lengths $L_1$
            and $L_2$.

            %
            % (c)
            \item From the characteristic equation for the
            equilibrium $(1,1)$, derived in part (b), the
            eigenvalues are
            \begin{align*}
                \lambda_{\pm}
                &=\frac{1}{2}\left[-(D+1)k_s
                \pm\sqrt{(D+1)^2k_s^2-4(Dk_s^2+\gamma)}\right]\\
                &=\frac{1}{2}\left[-(D+1)k_s
                \pm\sqrt{(D-1)^2k_s^2-4\gamma}\right].
            \end{align*}

            The temporal behaviour of a mode will be oscillatory
            if its eigenvalues have a non-zero imaginary component.
            This requires
            \begin{equation*}
                (D-1)^2k_s^2<4\gamma.
            \end{equation*}

            For $D\neq 1$ this can be written as
            \begin{equation*}
                k_s<\frac{2\sqrt{\gamma}}{|D-1|}.
            \end{equation*}

            Since the smallest permissible value of $k_s$ occurs
            when $n_1=n_2=1$, there will be at least one
            oscillatory mode provided
            \begin{equation*}
                \boxed{
                    \frac{1}{L_1^2}+\frac{1}{L_2^2}
                    <\frac{2\sqrt{\gamma}}{\pi^2|D-1|}.
                }
            \end{equation*}

            For every spatial mode to exhibit oscillatory decay
            we would require
            \begin{equation*}
                (D-1)^2k_s^2<4\gamma
            \end{equation*}
            for all permissible values of $k_s$. However, $k_s$
            is unbounded as $n_1$ or $n_2$ tends to infinity.
            Hence this is only possible if
            \begin{equation*}
                \boxed{D=1.}
            \end{equation*}

            In this case the eigenvalues reduce to
            \begin{equation*}
                \lambda_{\pm}=-k_s\pm\i\sqrt{\gamma}.
            \end{equation*}
            Thus every spatial mode exhibits oscillatory decay,
            with the same angular frequency $\sqrt{\gamma}$ but
            with a decay rate dependent on the spatial mode.
            In particular, at least one oscillatory mode always
            exists when $D=1$, irrespective of the domain lengths.
        \end{enumerate}
    }
    %
    %------------------------------------------------------------------
    %
\end{enumerate}
